Thesis is an autonomous options agent for skeptical judges. It cannot risk a dollar until it writes why the trade exists, when it is wrong, and the maximum amount it can lose.

SCOUT RANKS→GROK PROPOSES→CODE CONTROLS→ALPACA PROVES

THE PROBLEM

Most “AI traders” collapse analysis, risk, and execution into one opaque prompt. A confident hallucination then looks exactly like a valid trade.

Thesis separates those responsibilities. A deterministic scout narrows market breadth before Grok proposes a falsifiable idea; deterministic code decides whether that idea is tradable; Alpaca paper infrastructure proves what actually happened.

01 / THE AGENT PATH

One funnel. Six accountable steps.

  1. ObserveThe 29-name expanded universe is observed from live market data alongside paper-account state, positions, and fills.
  2. ScoutDeterministic stock factors rank the universe. Up to three stock-ranked candidates proceed even when the retained legacy vertical probe finds no feasible spread.
  3. ProposeGrok-4.6 must research the candidates through filtered Alpaca MCP snapshot and option-chain tools, then select one underlying and a bullish or bearish direction.
  4. StructureDeterministic code selects one long call (bullish) or long put (bearish): 14–45 DTE near 25 DTE, near the money but farther OTM when needed for the premium cap.
  5. GateMaximum loss is premium paid. A final hard control stack determines whether a simple single-leg limit/day buy-to-open order may proceed.
  6. RecordEvery decision, including unavailable data and abstention, retains its proposal, controls, tool trace, order state, fills, monitoring, and reconciliation context.

02 / DETERMINISTIC CONTROL PLANE

Language can suggest. It cannot authorize.

Paper endpoint only · active, unblocked account · options level 3 · valid MCP clock in agreement with SDK

Allowlisted underlying · valid conviction ≥ 0.35 · fresh two-sided quote · 14–45 DTE · market open

Premium ≤1% of equity · fewer than three broker positions before entry · ≤6% aggregate risk · one opening order per New York day · explicit execution enablement

Any failed gate produces a recorded no-trade or blocked decision. Grok never chooses contracts, sizes risk, or submits orders.

03 / ALPACA IN THE PATH

Tool evidence, not a screenshot.

Alpaca Trading and Market Data APIs provide account state, positions, option contracts and quotes, stock trades and bars, order status, portfolio history, and fill activities.

The official Alpaca MCP server is part of the agent path. Grok sees only filtered get_stock_snapshot and get_option_chain tools; the harness owns account, clock, order status, and the sole write path: place_option_order.

FAIL CLOSEDA blocked account, insufficient options level, clock disagreement, malformed MCP data, timeout, rejection, or a missing order ID stops the cycle. An ambiguous submission is terminal: no MCP retry and no CLI or SDK order fallback.

04 / THE AUDIT CONSOLE

Every claim links to evidence.

The live dashboard is read-only. It renders before broker data arrives, then reconciles an append-only SQLite decision ledger with Alpaca paper data in the background.

  • Grok thesis and deterministic gates
  • Sanitized API trace and exact blocked single-leg intent
  • Broker order state, fills, and position attribution
  • Exit state, realized and unrealized P&L, reconciliation delta, and equity curve

The current demo also supports a durable 30-minute weekday analysis-only cadence. Those cycles force execution off and cannot submit orders.

Evidence over assertion.

The model is creative where language is useful and powerless where deterministic controls are safer. Its reasoning, abstention, risk, tool use, and broker outcome can be judged from one screen.

THESIS

Propose. Prove. Execute.

An options agent that must show its work.

Thesis is an autonomous options agent that cannot risk a dollar until it writes why the trade exists, when it is wrong, and the maximum amount it can lose. Grok proposes a falsifiable idea; deterministic code decides whether it is tradable; Alpaca paper infrastructure proves what occurred.

AI LOGIC

Creative thesis. Bounded authority.

Each cycle reads Alpaca paper-account state, positions, fills, and market data. Grok-4.6 can research only the deterministic stock-ranked shortlist through two filtered Alpaca MCP tools, then selects one underlying and a bullish or bearish direction. It never chooses the final contract, sizes risk, or submits orders.

At qualifying conviction, code selects one long call or put: 14–45 DTE near 25 DTE, near ATM but farther OTM when needed to fit the 1% equity premium cap. Maximum loss is premium paid.

RISK GATES

Language cannot authorize.

Hard controls require a paper endpoint; active, unblocked account; options level 3; valid MCP clock agreeing with the SDK; allowlisted underlying; valid conviction ≥0.35; fresh two-sided quote; 14–45 DTE; market open; premium ≤1% of equity; fewer than three broker positions before entry; ≤6% aggregate risk; one opening order per New York day; and explicit execution enablement.

Any failure records a no-trade or blocked decision. Abstention is evidence, not an error.

ALPACA INFRASTRUCTURE

Tool evidence, not a screenshot.

Alpaca APIs supply deterministic scouting, monitoring, fills, positions, and portfolio history. The official Alpaca MCP server supplies constrained Grok research plus harness-owned account, clock, order-status, and guarded place_option_order calls.

Only a canonical single-leg limit/day buy-to-open option order can cross the write boundary. Malformed data, account restrictions, clock disagreement, timeout, rejection, or a missing order ID stops the cycle. There is no retry or alternate write path after an ambiguous result.

A durable 30-minute weekday analysis-only capability always forces execution off.

EVIDENCE & PERFORMANCE

The read-only FastAPI console reconciles an append-only SQLite decision ledger with Alpaca orders, fills, positions, and portfolio history. Judges can inspect the thesis, gates, sanitized MCP/API trace, single-leg intent, broker state, realized and unrealized P&L, reconciliation delta, and equity curve. Values come directly from the submitted paper account; none are hardcoded.

WHY THESIS

Evidence over assertion. The model is creative where language is useful and powerless where deterministic controls are safer. Every trade—and every refusal to trade—is explainable from one screen.
